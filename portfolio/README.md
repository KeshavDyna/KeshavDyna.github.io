# Keshav Puri — Portfolio

A minimal, futuristic, responsive portfolio built with React, JSX, CSS, and Vite.

## Run locally

You need Node.js and npm installed.

```bash
# 1. Move into the project folder
cd keshav-portfolio

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Create a production build

```bash
npm run build
npm run preview
```

The production-ready website is generated in the `dist/` folder.

## Personalize it

- Edit the intro, about section, interests, and toolkit in `src/App.jsx`.
- Update `GITHUB` and `EMAIL` near the top of `src/App.jsx` if your links change.
- Add or replace project objects in the `projects` array in `src/App.jsx`.
- Change colors, spacing, and responsive styles in `src/index.css`.
